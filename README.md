# 용마 점주 아카데미 · 용마거리 점주 온라인 강의실

용마거리 지역 점주님들이 로그인해서 3D 강의실에 들어가, 자리에 앉아 강의를 듣는 시연 페이지입니다.

- 시연 주소: https://whaleguard.github.io/yongma-academy/
- 흐름: 회원가입/로그인 → 강의실 입장 → 자리에 앉기 → 강의 목록에서 **수강신청** → **수업보기**
- 진도: 유튜브 플레이어에서 실제로 재생된 구간만 합산 (건너뛰기는 진도에 안 들어감) · 마지막 위치에서 **이어보기** · 90% 이상 보면 **수료** + 수료증(PNG)
- 강의별 실행 체크리스트·메모(계정에 저장), 질문 게시판(모두에게 공개), 같은 방 **함께 듣기**
- 엔진: 맥스데이 라이프 공용 코드(https://github.com/whaleguard/maxday-life) — 이 저장소는 이름·로고·공간 구성만 다른 진입 페이지
- 계정 저장: 시연판은 공개 중계(MQTT)에 암호화된 비밀번호 값만 저장합니다. 정식 운영은 `server/server.js`(scrypt 암호화·세션 토큰·진도 저장)를 띄우고 `?server=wss://도메인/ws` 로 연결하세요.
- 강의 영상: 각 채널이 유튜브에 공개한 영상을 유튜브 플레이어로 재생 (거래처 자체 강의로 교체 가능: `window.MDL_BRAND.lectures`)
- 일반 방문자용 3D 마을(용마미식거리)과는 따로 운영하는 점주 전용 자매 서비스: https://whaleguard.github.io/yongma-land/
